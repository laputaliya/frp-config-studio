# FRP Config Studio（FRP 配置工坊）

Web 可视化的 FRP 配置生成、打包与远程管理工具。

## 功能特性

- **程序包管理** — 上传多平台 FRP 压缩包，自动识别版本和系统架构，同版本合并
- **服务端配置** — 可视化配置 frps，实时预览 TOML，一键打包下载
- **客户端配置** — 配置 frpc 公共参数和代理规则（TCP/UDP/HTTP/HTTPS/STCP/XTCP）
- **方案管理** — 保存和加载配置方案，客户端可关联服务端方案自动同步参数
- **远程管理** — 查看已部署 FRP 服务端状态、代理列表、客户端详情，支持远程重载
- **用户认证** — 登录/退出，多用户管理
- **打包部署** — 生成含二进制、TOML 配置、启动脚本、使用说明的 ZIP 部署包

## 快速开始

```bash
npm install
npm run dev        # 开发模式（:5173 + :3001）
node server.js     # 生产模式（:3001）
```

默认账户：`admin` / `admin`

## 使用流程

1. 上传 FRP 压缩包（`frp_0.61.0_linux_amd64.tar.gz` 格式）
2. 创建服务端方案，填写远程服务器地址和面板信息
3. 创建客户端方案，关联服务端方案自动同步参数
4. 选择目标平台，打包下载
5. 在远程管理页面连接已部署的服务端

## 技术栈

Node.js 18+ / Express / React 18 / Bootstrap 5 / Vite / archiver
