```
│ 侧边栏    │ 顶部栏：📦 页面标题      [admin] [退出]  │

│ 配置工坊  │ Tab: [首页] [程序包] [服务端] [✕]       │
│          ├─────────────────────────────────────────┤
│ ▸ 首页   │           内容区域                      │

│  服务端   │                                         │
│  客户端   │                                         │

│ 系统管理  │                                         │
│  用户    │                                         │
└──────────┴─────────────────────────────────────────┘
```

## 2. 远程管理页（FRP Dashboard 风格）

### 布局
- 左侧：服务端连接列表（从服务端方案自动读取，绿点标识）
- 右侧：三段式分类导航（概览/代理/客户端）+ 内容

### 概览
- 6 个统计卡片（版本、客户端数、连接数、端口、流入/流出流量）
- 虚拟主机与高级配置面板（子域名、HTTP/HTTPS/KCP/QUIC 端口、连接池等）
- 代理类型分布
- 刷新按钮 + 重载配置按钮

### 代理
- 类型筛选按钮（全部/tcp/udp/http/https/stcp/xtcp）
- 表格列：名称、类型、本地地址、远程端口、今日流入、今日流出、状态
- **点击行** → 展开代理详情面板：
  - 名称、类型、状态、客户端 ID、本地地址
  - 子域名/自定义域名（http/https 类型）
  - 今日流入/流出、累计流入/流出
  - 当前连接数、上次启动/关闭时间
  - **流量跟踪柱状图**：并排绿柱（流入）红柱（流出），时间轴标注"今天/昨天/前天/N天前"，图例+峰值
- 刷新按钮

### 客户端
- 表格列：客户端 ID、主机名、IP、在线状态
- **点击行** → 展开客户端详情面板：
  - 客户端 ID、运行 ID、版本、主机名、IP、通信协议、首/末次连接、在线状态
  - **关联代理列表**：该客户端下的代理，点击代理自动切换到代理页并展开详情
- 刷新按钮

### 交互
- 所有破坏性操作二次确认
- API 请求中按钮禁用+加载态
- Toast 通知（3s 自动消失）
