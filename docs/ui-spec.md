# UI 规格文档

> **文档版本**：2.0
> **最后更新**：2026-06-04

---

## 1. 整体框架

管理后台布局：左侧可折叠侧边栏 + 右侧主内容区（顶部栏 + Tab 标签页 + 内容区）。

```
┌──────────┬─────────────────────────────────────────┐
│ 侧边栏    │ 顶部栏：📦 程序包管理    [admin 管理员] [退出] │
│ ⚙ FRP   ├─────────────────────────────────────────┤
│ 配置工坊  │ Tab: [首页] [程序包管理] [服务端配置] ... [✕] │
│          ├─────────────────────────────────────────┤
│ ▸ 首页   │                                         │
│          │           内容区域                       │
│ FRP管理  │                                         │
│  程序包   │                                         │
│  服务端   │                                         │
│  客户端   │                                         │
│  远程    │                                         │
│          │                                         │
│ 系统管理  │                                         │
│  用户    │                                         │
├──────────┤                                         │
│ [◀ 收起] │                                         │
└──────────┴─────────────────────────────────────────┘
```

- 侧边栏可折叠（240px ↔ 60px），移动端默认 60px
- Tab 标签页：点击菜单打开，可关闭（首页固定）
- 顶部栏：当前页面标题 + 用户名 + 退出按钮

---

## 2. 登录页

- 居中卡片，品牌标识 + 用户名密码表单
- 默认账户 admin/admin

---

## 3. 首页

- 系统介绍 + 6 个功能卡片
- 使用流程：上传程序包 → 配置服务端 → 配置客户端 → 打包下载 → 部署 → 远程管理

---

## 4. 程序包管理页

- 左侧：上传区（拖拽、文件选择、版本号自动解析）
- 右侧：版本列表表格
  - 版本号 + 默认标识
  - 平台标签（带 OS 图标，如 linux/amd64、windows/amd64）
  - 上传时间、设为默认、删除

---

## 5. 服务端配置页

- 左侧：方案列表（点击加载）+ 新建按钮
- 右侧上：版本+平台选择器、方案名称、保存/另存为/删除按钮
- 右侧左：配置表单（远程服务器地址、端口、令牌+随机生成、面板信息等）
- 右侧右：frps.toml 深色预览

---

## 6. 客户端配置页

- 同服务端布局
- 额外：关联服务端方案下拉框（蓝色边框卡片），自动同步地址/端口/令牌
- 代理规则卡片：名称+类型+表单字段，动态显示类型特有字段

---

## 7. 远程管理页

FRP Dashboard 风格：
- 左侧：远程服务端列表（从服务端方案自动读取，绿点在线标识）
- 右侧：三段式分类导航（概览/代理/客户端）
- 概览：6 个统计卡片 + 虚拟主机与高级配置面板 + 代理类型分布
- 代理：类型筛选按钮 + 表格
- 客户端：表格 + 点击展开详情面板

---

## 8. 用户管理页

- 用户表格：用户名、角色、创建时间
- 添加/编辑弹窗：用户名、密码、角色（管理员/普通用户）

---

## 9. 通用交互

- 所有文案中文化
- 破坏性操作二次确认
- API 请求中按钮禁用 + 加载态
- Toast 通知（成功绿/失败红，3s 消失）
- 空状态引导提示
