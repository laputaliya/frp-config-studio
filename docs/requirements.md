## 1. 项目背景

FRP（Fast Reverse Proxy）是一个高性能的反向代理应用，常用于内网穿透。传统方式需要手动编写配置文件、寻找对应平台的二进制文件、打包传输，操作繁琐且容易出错。

本项目是一个 **Web 可视化的 FRP 配置生成、打包与远程管理工具**。

---

## 2. 项目目标

- 上传和管理多平台、多版本的 FRP 程序包
- 可视化配置 frps（服务端）和 frpc（客户端）参数，生成官方 TOML 格式配置
- 客户端配置可关联服务端方案，自动同步地址、端口和令牌
- 配置方案保存与复用
- 一键打包部署 ZIP（含二进制、TOML 配置、平台对应启动脚本、使用说明）
- 远程管理已部署的 FRP 服务端，查看状态、代理和客户端详情
- 用户认证与系统管理

## 4. 功能需求

### 4.1 程序包管理

- 从文件名自动识别版本号、OS、架构（如 `frp_0.61.0_linux_amd64.tar.gz`）
- 同版本不同平台上传后合并存储，不覆盖
- 支持 `.tar.gz` 和 `.zip` 格式
- 版本列表展示各平台标签（Linux/Windows/macOS 图标区分）
- 支持设为默认版本、删除版本（可删除单个平台）

### 4.2 服务端配置

- 填写远程服务器地址、绑定端口、认证令牌、管理面板信息、虚拟主机、日志等
- 版本 + 平台选择器
- 实时预览 frps.toml（官方格式：camelCase、dot-notation）
- 认证令牌支持随机生成
- 方案保存/加载/另存为/删除

### 4.3 客户端配置

- 公共参数：服务端地址、端口、令牌、管理面板、日志
- 代理规则 CRUD：支持 tcp/udp/http/https/stcp/xtcp，动态表单
- 关联服务端方案：自动同步 serverAddr、serverPort、auth.token
- 方案保存/加载/另存为/删除

### 4.4 方案管理

- JSON 格式存储，含版本号、平台、关联服务端方案等元数据
- 左侧方案列表，点击加载，显眼位置操作按钮

### 4.5 打包下载

- 按版本 + 平台选择对应二进制文件
- ZIP 包含：二进制、TOML 配置、平台对应启动脚本（.sh/.bat）、README.txt
- Windows 平台：exe 后缀 + bat 脚本
- Linux/macOS 平台：sh 脚本 + 可执行权限提示

### 4.6 远程服务端管理

- 从服务端方案自动读取连接信息（需填写远程服务器地址和面板信息）
- 概览：版本、客户端数、连接数、流量统计、虚拟主机配置、代理类型分布
- 代理列表：聚合全部 6 种类型，按类型筛选，流量和状态
- 客户端列表：点击查看详情（客户端ID、主机名、IP、版本、连接时间、在线状态）
- 远程重载配置
- 每 10 秒自动刷新

### 4.7 用户认证与系统管理

- 登录/退出，Token 会话认证（24h 有效）
- 所有 API 需认证访问（`/api/auth/login` 和 `/api/health` 除外）
- 用户管理：添加/编辑/删除用户，admin/user 角色
- 默认管理员：admin / admin

## 5. 非功能需求

| 需求     | 描述                                                      |
| -------- | --------------------------------------------------------- |
| 易用性   | 管理后台布局，侧边栏可折叠，Tab 标签页，方案列表可见       |
| 跨平台   | Node.js 18+，可运行在 Windows / Linux / macOS 上           |
| 安全性   | 登录认证、Token 会话、密码不回显、100MB 上传限制            |
| 性能     | 上传解压、配置生成、打包操作 3 秒内完成                     |
| 兼容性   | 配置输出兼容 FRP v0.52+ TOML 格式                           |

---

## 6. 验收标准

1. 上传多平台 FRP 包，同版本合并，各平台识别正确
2. 服务端和客户端配置生成符合官方 TOML 格式
3. 客户端关联服务端方案后自动同步参数
4. 打包 ZIP 含正确的二进制、配置、启动脚本、说明文件
5. 远程管理正确展示 serverinfo、proxies、clients
6. 登录认证有效，未登录无法访问 API
7. 用户管理正常增删改
8. 界面管理后台布局，中文化，响应式
