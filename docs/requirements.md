## 1. 项目背景

FRP（Fast Reverse Proxy）是一个高性能的反向代理应用，常用于内网穿透。本项目是一个 **Web 可视化的 FRP 配置生成、打包与远程管理工具**。

---

## 2. 项目目标

- 上传和管理多平台、多版本的 FRP 程序包（同版本不同平台合并存储）
- 可视化配置 frps/frpc 参数，生成 FRP 官方 TOML 格式配置
- 客户端配置可关联服务端方案，自动同步地址、端口和令牌；子域名受服务端 subdomainHost 控制
- 配置方案保存/加载/另存为/删除
- 一键打包部署 ZIP（含二进制、TOML 配置、平台对应启动脚本、README）
- 远程管理已部署的 FRP 服务端：概览、代理、客户端详情
- 代理详情面板：域名信息、流量统计柱状图、带宽跟踪
- 客户端详情面板：关联代理列表，点击代理可直接跳转
- 用户认证（Token + bcrypt 密码哈希）+ 角色授权（admin/user）
- 管理后台布局（可折叠侧边栏、Tab 标签页、登录页）
- 安全加固（路径穿越防护、CORS 限制、Helmet、频率限制）

---

## 3. 功能需求

### 3.1 程序包管理
- 文件名自动识别版本+OS+架构，同版本不同平台上传统一合并
- 支持 `.tar.gz` / `.zip`，含 `.exe` 后缀自动识别
- 版本列表展示平台标签，支持设默认、删除

### 3.2 服务端配置
- 远程服务器地址、端口、Token（支持随机生成）、Dashboard 面板、虚拟主机、日志
- 实时预览 TOML（camelCase + dot-notation）

### 3.3 客户端配置
- 公共参数 + 代理规则 CRUD（tcp/udp/http/https/stcp/xtcp）
- 关联服务端方案自动同步参数；子域名继承服务端 subdomainHost

### 3.4 远程管理
- 从服务端方案自动读取连接信息
- 概览：统计卡片 + 虚拟主机配置 + 代理类型分布
- 代理列表：类型筛选、点击行 → 详情面板（域名、流量柱状图、累计流量）
- 客户端列表：点击行 → 详情面板（含关联代理列表，可跳转代理页）
- 支持手动刷新 + 10s 自动刷新

### 3.5 安全
- 登录 Token 认证（bcrypt 密码哈希）、角色授权（admin/user）
- 路径穿越防护、Helmet 安全头、CORS 限制、登录频率限制

---

## 4. 验收标准

1. 上传多平台 FRP 包，同版本合并，`.exe` 后缀自动识别
2. 配置生成符合 FRP 官方 TOML 格式，customDomains 为数组
3. 客户端关联服务端后子域名/端口/令牌自动同步
4. 打包 ZIP 按平台生成对应启动脚本和 README
5. 远程管理展示 serverinfo/proxies/clients，代理有流量柱状图
6. 登录认证有效，普通用户无法执行管理操作
7. 路径穿越、SSRF、明文密码等安全问题已修复
